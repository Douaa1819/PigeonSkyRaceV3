# 🚀 **Project: Securing an application with Keycloak, HTTPS & CI/CD**

Welcome to the **Keycloak** integration project for authentication and authorization management, secured with **HTTPS/SSL**, and automatically deployed using a **Jenkins CI/CD** pipeline. 🎯

---

## 🔧 **Technologies Used**
- **Backend** : Spring Boot 🚀
- **Security** : Keycloak, OAuth 2.0 🔒
- **SSL/TLS Certificate** : HTTPS 🌐
- **Deployment** : Docker 🐳, Jenkins 🛠️

---

## 📦 **Prerequisites**

Before you start, make sure you have:
- **Java 17** or newer ☕
- **Maven** for dependency management 📦
- **Docker** installed for deployment 🐳
- **Keycloak** configured on your environment 🔑
- **Jenkins** installed for automation ⚙️

---

## 🚀 **Installation and Configuration**

### **1. Clone the Project**
```bash
git clone https://github.com/Douaa1819/PigeonSkyRaceV3
cd PigeonSkyRaceV3
```

## 🔑 **Main Features**
```plaintext
1. Keycloak integration for authentication and authorization.
2. Securing REST endpoints with OAuth 2.0 and Spring Security.
3. Encrypting communications using HTTPS and an SSL/TLS certificate.
4. Automating the CI/CD pipeline with Jenkins.
5. Deploying a Docker image of the application.
6. CORS validation to secure request origins.
```
