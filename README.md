# 🚀 **Projet : Sécurisation d'une application avec Keycloak, HTTPS & CI/CD**

Bienvenue dans le projet d'intégration de **Keycloak** pour la gestion de l'authentification et de l'autorisation, sécurisé avec **HTTPS/SSL**, et déployé automatiquement grâce à un pipeline **Jenkins CI/CD**. 🎯

---

## 🔧 **Technologies Utilisées**
- **Backend** : Spring Boot 🚀  
- **Sécurité** : Keycloak, OAuth 2.0 🔒  
- **Certificat SSL/TLS** : HTTPS 🌐  
- **Déploiement** : Docker 🐳, Jenkins 🛠️  

---

## 📦 **Prérequis**

Avant de commencer, assure-toi d'avoir :  
- **Java 17** ou plus récent ☕  
- **Maven** pour la gestion des dépendances 📦  
- **Docker** installé pour le déploiement 🐳  
- **Keycloak** configuré sur ton environnement 🔑  
- **Jenkins** installé pour l'automatisation ⚙️  

---

## 🚀 **Installation et Configuration**

### **1. Cloner le Projet**
```bash
git clone https://github.com/Douaa1819/PigeonSkyRaceV3
cd PigeonSkyRaceV3
```

## 🔑 **Fonctionnalités Principales**
```plaintext
1. Intégration de Keycloak pour l'authentification et l'autorisation.
2. Sécurisation des endpoints REST avec OAuth 2.0 et Spring Security.
3. Chiffrement des communications grâce à HTTPS et un certificat SSL/TLS.
4. Automatisation du pipeline CI/CD avec Jenkins.
5. Déploiement d'une image Docker de l'application.
6. Validation CORS pour sécuriser les origines des requêtes.
```
